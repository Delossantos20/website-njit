5 practices you should do when creating a webpage

  1. Use an organized structure to make it readable
  2. Use another web page when trying to separate topics
  3. Maintain proper indentation
  4. Keep styles external
  5. conduct spell checs regularly

5 practices you should avoid when creating a webpage

  1. Avoid writing CSS directly inside tags
  2. Avoid skipping heading levels
  3. Avoid empty or missing links
  4. Avoid mixing upper with lower case
  5. Avoid space hacks
